# Yes Cal 🍚

LINE chatbot นับแคลอรี่สำหรับสองคน — พิมพ์หรือส่งรูปอาหารในกลุ่ม LINE แล้วบอทประเมินแคลให้ พร้อมหน้าเว็บดูสถิติ

```
LINE (กลุ่ม: เรา + แฟน + OA)
      │ webhook
      ▼
Cloudflare Worker ──► D1 (users, meals, weights)
      │           ──► Gemini API (ประเมินแคลจากข้อความ/รูป)
      ▼
ตอบกลับในแชท + เตือนกลุ่มชาเลนจ์ทุกวัน 22:00 (Cron Trigger)
      +
หน้าเว็บ dashboard (กราฟ 14 วัน, น้ำหนัก, มื้ออาหารวันนี้)
```

## ฟีเจอร์ / คำสั่งในแชท

| พิมพ์ | ผลลัพธ์ |
|---|---|
| `ตั้งเป้า` | ถามเพศ/อายุ/ส่วนสูง/น้ำหนัก/กิจกรรม/เป้าหมาย → คำนวณ TDEE (Mifflin-St Jeor) ตั้งเป้าแคล + โปรตีนรายวัน |
| `ข้าวมันไก่ 1 จาน` | ประเมินแคล + บันทึก + บอกว่าวันนี้เหลืออีกเท่าไหร่ |
| ส่งรูปอาหาร 📷 | Gemini vision ประเมินจากรูป |
| `เป้าโปรตีน 140` | ตั้งเป้าโปรตีนเองแทนค่าที่คำนวณให้ |
| `น้ำหนัก 65.5` | บันทึกน้ำหนัก + เทียบครั้งก่อน |
| `สรุป` | ยอดวันนี้ของทั้งคู่ แยกคน + มื้ออาหาร |
| `สัปดาห์` | ย้อนหลัง 7 วัน + ค่าเฉลี่ย |
| `ลบล่าสุด` | ลบรายการอาหารล่าสุดของวันนี้ |
| `ล้างวันนี้` | ลบรายการอาหารวันนี้ทั้งหมดของตัวเอง (เริ่มนับใหม่) |
| `เป้าหมาย` | ดูเป้าที่ตั้งไว้ |
| `คำสั่ง` | วิธีใช้ |
| — | ฝั่งแคลอรี่ไม่มี push อัตโนมัติ อยากดูยอดเมื่อไหร่พิมพ์ `สรุป` ได้เลย |

เป้าหมายมี 4 แบบ กำหนดทั้งแคลอรี่และโปรตีนต่อน้ำหนักตัว:

| เป้าหมาย | แคลอรี่ | โปรตีน |
|---|---|---|
| สุขภาพทั่วไป | TDEE พอดี | 0.9 g/กก. (ช่วงแนะนำ 0.8–1.0) |
| กระชับสัดส่วน/เฟิร์ม | TDEE พอดี | 1.4 g/กก. (1.2–1.6) |
| สร้างกล้ามเนื้อ | TDEE +400 | 1.9 g/กก. (1.6–2.2) |
| ลดไขมัน/ลีนหุ่น | TDEE −500 | 2.0 g/กก. (1.8–2.2) |

บอทแยกว่าใครกินจาก userId ของ LINE ที่ติดมากับทุกข้อความ — ไม่ต้องพิมพ์ชื่อ
ข้อความคุยเล่นทั่วไปบอทจะเงียบ ไม่แทรกกลางแชท

## โหมดชาเลนจ์ออกกำลังกาย 💪

บอทตัวเดียวกันทำงานได้ 2 โหมด แยกตามห้องแชท (เก็บใน `chat_targets.mode`)
กลุ่มไหนพิมพ์ **`ออกกำลังกาย`** จะเปลี่ยนจากนับแคลเป็นเช็คว่าใครออกกำลังกายวันนี้แล้วบ้าง
(พิมพ์ `โหมดชาเลนจ์` ก็ได้เหมือนกัน — คำสั่งเดิมยังใช้ได้)

| พิมพ์ | ผลลัพธ์ |
|---|---|
| ส่งรูป**หน้าจอสรุปผล** 📸 | นาฬิกา / แอปวิ่ง / หน้าจอลู่วิ่ง ที่เห็นตัวเลข → เช็คอินให้ พร้อมอ่านเวลาและแคลอรี่จากหน้าจอ |
| ส่งรูปยิม/รองเท้า/เซลฟี่ | **ไม่นับ** — บอทขอหลักฐานที่มีตัวเลขแทน |
| `วิ่ง 5 กม.` `วิดพื้น 50 ครั้ง` | เช็คอินจากข้อความ — **ต้องมีจำนวน** (นาที/ครั้ง/กิโล/เซ็ต) |
| `วิ่ง` `วิดพื้น` `ออกกำลังกาย` | **ไม่นับ** — บอทขอจำนวนเพิ่ม |
| `เข้าร่วม` | สมัครเข้าชาเลนจ์ (ทุกคนพิมพ์คนละครั้ง) |
| `วันนี้` | ใครออกแล้ว / ใครยังไม่ออก |
| `สมาชิก` | รายชื่อคนที่เข้าร่วมชาเลนจ์ทั้งหมด |
| `อันดับ` | ตารางคะแนน 7 วันล่าสุด + สถิติรวม |
| `เตือน` | แท็ก @ชื่อ คนที่ยังไม่ออกวันนี้ ให้เด้งแจ้งเตือนถึงตัว (เรียกเองได้ทุกเมื่อ) |
| `ลบ` | ลบรายการเช็คอินของตัวเองวันนี้ |
| `@ชื่อเพื่อน ลบ` / reply ที่รูป + `ลบ` | ลบรายการของคนนั้น (ถ้ามีหลายรายการ บอทจะให้เลือกหมายเลข เช่น `ลบ 1`) |
| `เมื่อวาน` | ย้ายรายการล่าสุดของตัวเองไปเป็นของเมื่อวาน |
| `@ชื่อเพื่อน เมื่อวาน` | ย้ายรายการล่าสุดของคนที่ถูกแท็ก — ใช้ได้กับรายการเก่าด้วย |
| reply ที่รูป **หรือที่ข้อความบอท** + `เมื่อวาน` | ย้ายรายการนั้น (ใช้ `quotedMessageId` เทียบกับทั้ง `message_id` และ `reply_message_id`) |
| `เมื่อวานวิ่ง 5 กม.` | บันทึกใหม่ลงวันเมื่อวานเลย |
| `ออกจากชาเลนจ์` | ถอนตัว |
| `โหมดแคลอรี่` | สลับกลับเป็นบอทนับแคล |
| (อัตโนมัติ 22:00) | แท็ก @ชื่อ คนที่ยังไม่ออกกำลังกายวันนี้ |

คำว่า `ออกกำลัง` / `ออกกำลังกาย` เฉย ๆ **ไม่ใช่การเข้าร่วมและไม่ใช่การเช็คอิน** — เป็นแค่คำสั่งเปิดโหมด
เช็คอินต้องส่งรูปหน้าจอสรุปผล หรือพิมพ์ให้มีจำนวน เช่น `วิ่ง 5 กม.` `วิดพื้น 50 ครั้ง`

- คลังข้อความอยู่ที่ `src/jokes.js` สุ่มทุกครั้งจะได้ไม่ซ้ำ — เพิ่มบรรทัดใหม่ได้เลย
  **ตอนเช็คอินบอทจะไม่ชม** ตอบรับสั้น ๆ พอ (โดนชมทุกครั้งแล้วอึดอัด) ส่วนตอนทวง 22:00 ยังกวน ๆ ได้
  ล้อความขี้เกียจได้ แต่ไม่ล้อรูปร่างหรือน้ำหนักใคร
- **ย้อนหลังได้ 1 วัน**: พิมพ์ `เมื่อวาน` / `อันนี้คือเมื่อคืน` เพื่อย้ายรายการล่าสุดของตัวเอง
  แก้ให้เพื่อนได้ 2 ทาง: **แท็กชื่อเขา** (`@Erk เมื่อวาน` — ใช้ `mention.mentionees`, ได้กับรายการเก่าด้วย)
  หรือ **reply ที่รูปเช็คอิน หรือที่ข้อความยืนยันของบอท** แล้วพิมพ์ `เมื่อวาน` (บอทเก็บทั้ง id รูปและ id ข้อความที่ตอบไป)
  รายการที่เช็คอินไว้ก่อนเพิ่มคอลัมน์เหล่านี้จะ reply ไม่ติด ให้ใช้วิธีแท็กชื่อแทน
  ประโยคที่พูดถึงเมื่อวานแต่ไม่เกี่ยวกับการออกกำลังกาย (เช่น "กินข้าวเมื่อวานอร่อยมาก") บอทจะไม่ยุ่ง
- นับ **streak** วันติดต่อกันให้อัตโนมัติ ส่งรูปซ้ำในวันเดียวกันได้ (นับเป็นรอบที่ 2, 3...)
- ข้อความคุยเล่นและรูปอื่น ๆ ในกลุ่มบอทจะเงียบ ไม่แทรก
- การแท็กใช้ `mention.mentionees` ของ LINE (สูงสุด 20 คน/ข้อความ) วางไว้ต้นข้อความเสมอเพื่อให้ index ตรง ถ้าแท็กพลาดจะส่งข้อความธรรมดาแทนอัตโนมัติ
- ข้อความจะถูกกรองด้วยคำก่อน (`WORKOUT_HINTS`) แล้วค่อยส่งให้ AI — กลุ่มใหญ่คุยกันเยอะจะได้ไม่เปลืองโควตา
- ต้องให้ทุกคนพิมพ์ `เข้าร่วม` เอง (รวมถึงคนที่เปิดโหมด) เพราะ LINE เปิดให้ดึงรายชื่อสมาชิกกลุ่มเฉพาะ OA ที่ verified แล้วเท่านั้น
  ส่วนคนที่ส่งรูปเช็คอินโดยยังไม่ได้สมัคร บอทจะเพิ่มให้อัตโนมัติ (ถือว่าร่วมแล้วโดยปริยาย)

> ⚠️ ข้อความ push (เตือน 22:00) นับโควตาข้อความของ LINE OA ส่วนการ reply เมื่อมีคนพิมพ์หานั้นฟรีไม่จำกัด
> ถ้ากลุ่มใหญ่แล้วโควตาไม่พอ ให้ปิด cron 22:00 แล้วใช้คำสั่ง `วันนี้` แทนได้

## สิ่งที่ต้องเตรียม

1. **Cloudflare API token** — dash.cloudflare.com → My Profile → API Tokens → Create Token
   - ใช้ template **"Edit Cloudflare Workers"** แล้วเพิ่ม permission: **Account → D1 → Edit**
2. **LINE Messaging API channel** — [developers.line.biz/console](https://developers.line.biz/console) → provider เดิม → Create a Messaging API channel
   - เอา **Channel secret** (Basic settings) และ **Channel access token** (Messaging API tab → issue)
   - เปิด **Allow bot to join group chats** (Messaging API tab)
   - ปิด Auto-reply / Greeting message ใน [LINE Official Account Manager](https://manager.line.biz)
3. **Gemini API key** — [aistudio.google.com/apikey](https://aistudio.google.com/apikey) (ฟรี ไม่ต้องผูกบัตร)

## ติดตั้ง

```bash
npm install

# 1) สร้างฐานข้อมูล D1 แล้วเอา database_id ที่ได้ไปใส่ใน wrangler.toml
npx wrangler d1 create yes-cal

# 2) สร้างตาราง
npm run db:migrate

# 3) ใส่ secrets
npx wrangler secret put LINE_CHANNEL_SECRET
npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN
npx wrangler secret put GEMINI_API_KEY
npx wrangler secret put DASHBOARD_KEY     # รหัสเปิดหน้าเว็บ ตั้งอะไรก็ได้

# 4) deploy
npm run deploy
```

ได้ URL มาแล้ว (เช่น `https://yes-cal.xxx.workers.dev`):

1. ไปที่ LINE Developers → Messaging API tab → **Webhook URL** ใส่ `https://yes-cal.xxx.workers.dev/webhook` → Verify → เปิด **Use webhook**
2. สร้างกลุ่ม LINE แล้วเชิญ OA เข้ากลุ่ม
3. พิมพ์ `ตั้งเป้า` ในกลุ่ม เริ่มใช้ได้เลย
4. หน้าเว็บสถิติ: เปิด URL หลัก แล้วใส่ DASHBOARD_KEY

## ค่าใช้จ่ายและโควตา

| อย่าง | โควตาฟรี | บอทใช้เท่าไหร่ |
|---|---|---|
| Cloudflare Workers + D1 + Cron | 100,000 request/วัน | หลักสิบ — ไม่มีทางเต็ม |
| LINE **reply** (ตอบเมื่อมีคนพิมพ์/ส่งรูป) | **ไม่จำกัด ฟรีเสมอ** | ทุกการเช็คอินและทุกคำสั่ง |
| LINE **push** (บอทส่งเอง) | จำกัดต่อเดือน ดูที่ [OA Manager](https://manager.line.biz) | **วันละ 1 ครั้ง** เฉพาะกลุ่มชาเลนจ์ (~30/เดือน) |
| Gemini `gemini-2.5-flash` | **20 ครั้ง/วัน** (ยืนยันจาก error จริง) | รุ่นสำรอง ใช้เมื่อรุ่นหลักเต็ม |
| Gemini `gemini-3.5-flash-lite` | สูงกว่ามาก — ดูตัวเลขจริงที่ [ai.dev/rate-limit](https://ai.dev/rate-limit) | รุ่นหลัก 1 ครั้งต่อ 1 รูป/1 ข้อความที่เข้าเงื่อนไข |

ระบบออกแบบให้ของหนักไปอยู่ฝั่ง **reply ซึ่งฟรีไม่จำกัด** ส่วน push ใช้แค่วันละครั้ง
เปิด `/api/health` ดู `usage_7d` เพื่อดูยอดเรียกจริงย้อนหลัง 7 วัน (นับทั้ง Gemini แยกตามรุ่น และ push)

ถ้าใช้หนักจน Gemini ไม่พอ เปิด billing ที่ Google AI Studio ได้ (จ่ายตามใช้จริง หลักบาทต่อเดือน)

## ค่าอ้างอิงโภชนาการ

`src/food-reference.js` เก็บตารางค่าอาหารไทย ~40 เมนู ที่บอทใช้ยึดก่อนให้ AI ประเมินเอง
(อ้างอิงตารางคุณค่าทางโภชนาการอาหารไทย กรมอนามัย 2561) อยากให้เมนูไหนแม่นขึ้น เพิ่มบรรทัดแล้ว deploy ได้เลย

**เช็คอินต้องมีตัวเลขเสมอ ทั้งรูปและข้อความ** — ใช้มาตรฐานเดียวกันทั้งสองทาง
- รูป: ต้องเป็นหน้าจอนาฬิกา/แอป/เครื่องออกกำลังกายที่อ่านตัวเลขได้ (รูปยิม รองเท้า เซลฟี่ ไม่นับ)
- ข้อความ: ต้องบอกจำนวน เช่น "วิ่ง 5 กม." "วิดพื้น 50 ครั้ง" (คำว่า "วิ่ง" หรือ "ออกกำลังกาย" ลอย ๆ ไม่นับ)

ถ้าไม่เข้าเกณฑ์ บอทจะขอเพิ่มให้แทนที่จะบันทึก — กันการเช็คอินลอย ๆ ที่ทำให้สถิติไม่มีความหมาย

**ฝั่งออกกำลังกายบอทไม่ประเมินตัวเลขให้** — เวลาและแคลอรี่จะแสดงเฉพาะเมื่อ
เจ้าตัวพิมพ์บอกเอง ("โยคะ 45 นาที") หรืออ่านได้จากหน้าจอนาฬิกา/แอปในรูป
เพราะแต่ละคนใช้เวลาไม่เท่ากัน การเดาแล้วแสดงเหมือนเป็นข้อเท็จจริงจะทำให้สถิติเพี้ยน

> ⚠️ ตัวเลขแคลจาก AI เป็นการประเมินคร่าว ๆ (คลาดเคลื่อน 20–30% โดยเฉพาะอาหารไทยที่น้ำมัน/กะทิไม่แน่นอน) ใช้ดูเทรนด์ได้ดี ไม่ใช่คำแนะนำทางการแพทย์

## แก้ปัญหา

**บอทเงียบ ไม่ตอบอะไรเลย** — เช็คก่อนว่า secret ครบไหม เปิด:
`https://yes-cal.<subdomain>.workers.dev/api/health?key=<DASHBOARD_KEY>`

- `LINE_CHANNEL_SECRET: set false` → บอทตรวจลายเซ็นไม่ผ่าน ปฏิเสธทุกข้อความ (อาการ: เงียบสนิท)
- `line_status: 401` → access token หาย/หมดอายุ บอทอ่านข้อความได้แต่ตอบกลับไม่ได้
- `gemini_status: 429` → โควตาวันนี้หมด (บอทจะบอกเองในแชท)

**secret หายหลัง deploy** — เกิดขึ้นได้ ให้ตั้งใหม่ทั้งชุด (ค่าจริงอยู่ที่ LINE Developers Console):

```cmd
(echo <CHANNEL_SECRET>| npx wrangler secret put LINE_CHANNEL_SECRET) && (echo <ACCESS_TOKEN>| npx wrangler secret put LINE_CHANNEL_ACCESS_TOKEN) && (echo <GEMINI_KEY>| npx wrangler secret put GEMINI_API_KEY) && (echo <DASHBOARD_KEY>| npx wrangler secret put DASHBOARD_KEY)
```

แล้วเปิด `/api/health` ยืนยันว่าขึ้น `set: true` ครบทั้ง 4 ตัว **ทำทุกครั้งหลัง deploy**
